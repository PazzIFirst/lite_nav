## 0. 为什么重画

这套图标一共 50 套 SVG 覆盖 71 种天气,卡片上的图标槽只有 **44×44 px**(Retina 88×88)。这 7 个属于「视程障碍 / 沙尘」两组,现在的画法是**横杠 + 散点**的组合:

- 44px 下缩略之后,「霾」和「浮尘」都只是一团棕点,「沙尘暴」和「强沙尘暴」只是几根斜杠的密度差,和**暴雨的雨丝几乎是同一个模子**;
- 「雾凇」是几根等距竖条,读作栅栏;「冻雾」是横杠 + 冰点,读作水滴。

已经试过一版重绘(菱形冰晶 / 冷杉剪影 / 沙墙等),**被否**,原因记在第 6 节,换方案时不要重复。

> 基线截图(7 个待重画图标,卡片实尺 + 8 倍放大)未入库,只留在交接目录里;
> 需要复现的话按 §6 起静态服务器 + 71 张全览图即可。

## 1. 硬约束(破了就不是"一家人")

全部写在 `frontend/js/weather-icons.js` 文件头,这里复述一遍:

| 约束 | 说明 |
|---|---|
| 画布 | `viewBox="0 0 48 48"`,内容控制在 `x/y ∈ [3, 45]` |
| 图元 | **只能用** `circle` / `rect`(带 `rx`)/ `ellipse` / `polygon` / `g`。**禁止** `path`(弧线参数写错肉眼极难发现,这是上一版踩过的坑) |
| 上色 | 纯实心 `fill`,**不用** `stroke` / `gradient` / `filter` / `opacity`。颜色一律走 class,由 `main.css` 上色 |
| 共用零件 | 云必须复用文件顶部的 `CLOUD` 常量(经 `cloud(cls, transform)` 调用),雪花用 `FLAKE`,闪电用 `BOLT`。各画各的云,拼起来就散了 |
| 命名 | `ICONS` 对象的键必须与 `weather-fx.js` 里 `FX_CONDITIONS` 的字符串**逐字一致**,改名会让动效和图标对不上 |
| 尺寸验收 | **按 44px 验收**,不是按 200px 大图 |

图标渲染链路:`ip-weather.js` → `renderWeatherIcon(host, 天气名)` → `resolveIconKey()` 查 `ICONS` → 塞进 44×44 的 `.wx-icon`。

## 3. 逐图设计 brief

每组先想清楚**要和谁区分**,再选符号。这一步跳过去,画出来就是四不像。

### 3.1 雾族(4 张一起看)

| 键 | 现在 | 必须区分于 |
|---|---|---|
| `轻雾` | 2 条雾带 | —— |
| `雾` | 4 条雾带 | `轻雾`:条数差 |
| `冻雾` | 3 条雾带 + 8 颗冰点 | `雾` / `雾凇` |
| `雾凇` | 竖条 + 横杠(栅栏) | `冻雾` / `雪` |

- **`轻雾` 和 `雾` 不要动**,它们是"纯雾带"的基准,新图标要能跟这两张并排而不违和。
- `冻雾` 的语义是"雾里有冰晶",冰是**悬浮/凝结**在雾里的,不是从天上挂下来的。
- `雾凇` 的语义是"雾凝结在地物(树枝、电线、草叶)上形成的白色冰晶层",关键在于**有附着物**。
- 两张都必须一眼和 `雾` 分开:靠冰色(`ic-ice` 青)是最省事的区分维度。

### 3.2 沙尘族(5 张一起看)

| 键 | 现在 | 强度阶梯位置 |
|---|---|---|
| `霾` | 3 根横杠 + 8 个点 | 能见度低,但**没有可见的沙**;天色发灰 |
| `浮尘` | 14 个等大圆点 | 沙**悬浮**在空气中,颗粒细、无运动 |
| `扬沙` | 3 根斜杠 + 7 个点 | 沙**从地面被卷起**,有运动 |
| `沙尘暴` | 5 根通栏斜杠 | 成片的沙**墙**推过来 |
| `强沙尘暴` | 7 根通栏斜杠 | 同上,更重 |

这张阶梯的核心矛盾:**强度只能靠密度表达时,五张会长成一个模子,而且会和`暴雨`雨丝的视觉撞车**。所以要给每一档一个**不同的构图**,而不是同一构图加密度:

- `霾`:重点是"天不透亮"——太阳/天空被压住是这一档最好认的符号;
- `浮尘`:重点是"悬浮"——颗粒,不要运动线;
- `扬沙`:重点是"离地"——需要一个地面元素,否则和浮尘分不开;
- `沙尘暴` / `强沙尘暴`:重点是"一整面墙"——需要一个有体量的面,而不是线。两档之间再用覆盖率(墙的高度/沙带的密度)拉开。

## 4. 验收标准(交图前自己过一遍)

1. **44px 一眼可辨**:把 7 张缩到实际尺寸并排看,3 秒内能说出各自是什么;至少能归到"冰雾 / 挂在东西上的冰 / 灰霾 / 悬浮沙 / 地上扬起的沙 / 沙墙"。
2. **同组不混**:`霾` 与 `浮尘` 不混;`浮尘` 与 `扬沙` 不混;`沙尘暴` 与 `强沙尘暴` 看得出强弱;`冻雾` 与 `雾凇` 不混。
3. **不与降水撞车**:`沙尘暴` 和 `大雨/暴雨` 并排不能像同一类东西。
4. **全览不违和**:71 张全览图里,这 7 张和云的画法看起来是同一只手画的(云形、圆角、粗细、留白节奏一致)。
5. `node scripts/static-checks.mjs` 全绿(语法 / 前端 import / DOM id 契约)。
6. 交付**三张图**:7 列改前改后 A/B、44px 实尺卡片、8 倍放大细节。

## 5. 已经试过、被否的方案(不要重复)

| 图标 | 试过的写法 | 结果 |
|---|---|---|
| 冻雾 | 雾带 + 8 颗等大冰点 | 像"水滴",太碎 |
| 冻雾 | 雾带 + 下垂的冰锥(三角形) | 44px 下像"在滴水",不像冻 |
| 冻雾 | 雾带 + 悬浮菱形冰晶 | 语义对了,但整体观感被否 |
| 雾凇 | 等距竖条 + 横杠(现状) | 像栅栏 |
| 雾凇 | 斜枝 + 一串冰球 | 像"串珠/项链" |
| 雾凇 | 冷杉剪影(冰色三角形叠三层) | **太具象**,和整套"元素化"的语言不搭,被否 |
| 霾 | 三根横杠 + 散点(现状) | 抽象,读不出是霾 |
| 霾 | 太阳 + 三根横贯的霾带 | 语义清楚了,但整体观感被否 |
| 浮尘 | 14 颗等大圆点(现状) | 像随机噪点 |
| 浮尘 | 大小错落的 14 颗圆点 | 略好,仍被否 |
| 扬沙 | 3 根斜杠 + 7 个点(现状) | 散,读不出"从地上起来" |
| 扬沙 | 地面条 + 3 根斜带 + 溅起颗粒 | 语义对了,仍被否 |
| 沙尘暴 / 强沙尘暴 | 5 / 7 根通栏斜杠(现状) | 和暴雨雨丝一个模子 |
| 沙尘暴 / 强沙尘暴 | 云形沙墙(沙色云剪影)+ 沙带 | 44px 下是"一坨棕色" |
| 沙尘暴 / 强沙尘暴 | 贴底的圆角矩形沙墙 + 上方沙带 | 像"一块砖/一条面包",被否 |

**共同教训**:

- 这套图标的语汇是**元素化的**(云、日、颗粒、条带),不接纳具象物件(树、房子、砖块);
- 44px 下,一个"面"要么是云形,要么会显得笨重;一条"线"必须是雾带/雨丝/沙带里的一种,否则会被误读;
- 想靠"加密度"表达强度,最后一定会和雨撞车。**每档必须换构图**。

## 6. 本地怎么跑、怎么出图

仓库是**零构建**的:前端就是一堆静态文件,后端只是 `/api`。所以看图不需要跑后端,给一个静态服务器就够了(API 404 不影响图标)。

### 6.1 起静态服务器

```bash
# 只需要看图时:随便一个静态服务器指向 frontend/
python3 -m http.server 8099 --directory frontend
# 打开 http://127.0.0.1:8099/
```

需要真实天气数据(看图标落在真实卡片里的样子)时,再起后端:

```bash
cd backend && npm install --cache /tmp/npm-cache   # 依赖装一次
PORT=3000 node src/server.js                        # 另开一个进程
```

### 6.2 出全量 71 张图

写一个临时页面(不要提交进仓库),按 `FX_CONDITIONS` 渲染 71 张卡:

```html
<link rel="stylesheet" href="/css/main.css">
<script type="module">
import { renderWeatherFx, resolveBgKey, displayName, FX_CONDITIONS } from '/js/weather-fx.js';
import { renderWeatherIcon } from '/js/weather-icons.js';
// 每 18 个一组,6 列,卡片 189×157,下面带 captions = 完整天气名
</script>
```

然后用 Playwright / `chrome --headless --screenshot` 分块截图:

```bash
BIN=/root/.cache/ms-playwright/chromium-1248/chrome-linux64/chrome
$BIN --headless --no-sandbox --window-size=1300,900 \
     --force-device-scale-factor=2 --screenshot=/tmp/gallery.png \
     http://127.0.0.1:8099/gh.html
```

### 6.3 出图的两个坑

- **截图必须换唯一文件名**(带时间戳)。反复往同一个路径写,看图的人会看到浏览器缓存的上一版,白干一轮。
- **卡片的图标槽是 44px**,别只给 200px 大图,一定要有 44px 实尺那一档。
